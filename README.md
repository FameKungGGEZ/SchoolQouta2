# ระบบสมัครโควตา ม.4 โรงเรียนตะพานหิน

ต้นแบบเว็บแบบ responsive สำหรับแสดงขั้นตอนสมัครนักเรียนและตรวจเอกสาร

## เปิดดู

เปิด `index.html` ในเบราว์เซอร์ หรือ deploy โฟลเดอร์นี้ไปยัง Vercel ได้เลย ไฟล์ `vercel.json` รองรับเส้นทาง `/admin/login` และ `/admin`

## บัญชีทดลอง

- นักเรียน: เลขประจำตัว `90001` วันเกิด `01/01/2553`
- ครู/ผู้ดูแล: เข้า `/admin/login` รหัสผ่าน `admin2569`

## ขอบเขตต้นแบบ

ข้อมูลผู้สมัคร เอกสาร และผลตรวจในเวอร์ชันนี้เป็นข้อมูลจำลองในเบราว์เซอร์ ยังไม่ได้เชื่อม Supabase Auth, Database หรือ Storage จึงไม่ใช้แทนระบบรับสมัครจริง การต่อ Supabase ต้องกำหนด schema, สิทธิ์ครู/นักเรียน (RLS), bucket เอกสารส่วนตัว และฟังก์ชันตรวจสอบข้อมูลก่อนนำไปใช้จริง

## ชุดข้อมูลทดสอบ

ไฟล์ `test-data/school-quota-test-data.xlsx` มีบัญชีนักเรียนสมมติ 100 คน และข้อมูลใบสมัครสมมติ 30 คน แบ่งเป็นข้อมูลพื้นฐานและคะแนนรายวิชา ห้ามใช้เป็นข้อมูลจริง
